Vaulty Skeleton

Kiroween · Skeleton Crew

One zero-knowledge skeleton.
Three completely different apps.

@vaulty/core is a zero-dependency vault SDK that runs entirely in your browser: draw a 5×5 pattern, get an AES-256-GCM encrypted vault with plausible deniability, a duress wipe and portable .vault backups. Nothing is ever sent to a server — these demos are static files.

  • PBKDF2-SHA256 × 600,000
  • random 256-bit master key
  • AES-256-GCM + AAD
  • 9-word recovery phrase
  • no “wrong pattern”
  • OPFS → IndexedDB
  • 0 runtime dependencies
Binary & media

GhostDrop

Binary & Media Whistleblower Vault — encrypt photos, PDFs and in-browser voice notes on the device.

  • Zero-leak in-memory previewer
  • Decoy vaults & duress panic wipe
  • Portable .vault archives
Launch GhostDrop → Structured records

CryptKeep

Air-Gapped Seed Phrase & TOTP 2FA Vault — typed JSON records with an RFC 6238 authenticator.

  • Masked seed words, reveal one at a time
  • 15-second clipboard auto-clear
  • Recover with the 9-word phrase
Launch CryptKeep → Drop-in adoption

InkVault

Drop-In “Save As Encrypted” Markdown Editor — write normally; encrypt only when you choose to.

  • No lock screen until you save
  • Save to / Open from encrypted vault
  • Lock clears the editor & wipes keys
